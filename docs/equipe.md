# Equipe

Projeto acadêmico da FATEC Zona Sul (Desenvolvimento de Software Multiplataforma), desenvolvido em grupo para uma barbearia de bairro real.

| Integrante (GitHub) | Frente | Responsabilidades |
|---|---|---|
| [@maxgodoydev](https://github.com/maxgodoydev) | Dados, Analytics e BI | Python e Pandas, SQL analítico, indicadores e consultas, Power BI e DAX, documentação analítica |
| [@Luck16Ash](https://github.com/Luck16Ash) | Backend Java | Agendamento: regras de negócio, disponibilidade, reservas, acesso do cliente, atendimento no balcão, site público e testes |
| [@alexandregial-cmd](https://github.com/alexandregial-cmd) | Backend Java | Base da aplicação, administração (catálogo, estoque, clientes, usuários, auditoria), segurança, painel de indicadores e Dockerfile |

As contribuições individuais podem ser conferidas no histórico de commits. O projeto começou no primeiro semestre com HTML, CSS, Bootstrap e JavaScript e foi remodelado com Java, Python, SQL, Analytics e BI. Esta versão foi finalizada com apoio de IA generativa (código, SQL, pipeline, documentação), declarado conforme as regras da FATEC/da disciplina.
