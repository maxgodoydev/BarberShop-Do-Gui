# Kanban inicial — plano de trabalho

> Quadro de partida criado para organizar o trabalho desta versão. Não é um histórico de execução acadêmica nem registra commits, reuniões ou tarefas passadas. Como a validação integrada ainda depende de ferramentas/ambiente externos, nada está marcado como **Concluído** apenas por existir um arquivo.

## A fazer

- [ ] Confirmar serviços, preços, durações, endereço, canais de contato e horários com a barbearia.
- [ ] Revisar a interface com as fotografias originais e o logo oficial, se forem disponibilizados.
- [ ] Executar o schema e o seed em PostgreSQL de teste e conferir as consultas.
- [ ] Compilar a aplicação com Java 21 e Maven; executar os testes automatizados.
- [ ] Configurar ambiente seguro de teste com credenciais administrativas exclusivas.
- [ ] Revisar a política de privacidade com o responsável pelo negócio antes de dados reais.
- [ ] Fazer deploy e verificar o comportamento da instância e do banco do provedor escolhido.

## Em andamento

- [ ] Revisão técnica do pacote gerado e coerência entre API, interface, SQL e documentação.

## Em revisão

- [ ] Interface responsiva, mensagens do formulário e estados de erro.
- [ ] Regras de transição de status e proteção padrão da área administrativa.
- [ ] Catálogo de métricas, dicionário de dados e documentação das hipóteses.

## Concluído

Nenhuma tarefa listada neste quadro. A seção ficará vazia até a equipe verificar e registrar critérios de conclusão.

## Critério para mover cartão

- **A fazer → Em andamento:** alguém assume a tarefa e registra o escopo.
- **Em andamento → Em revisão:** há um entregável verificável para uma segunda pessoa revisar.
- **Em revisão → Concluído:** os critérios de aceite foram testados e as evidências podem ser apontadas.
